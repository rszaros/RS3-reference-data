# RS3 reference data

This folder is reference data only (RS3 game exports, RuneScape Wiki data and
notes). Start with `README.md`: it explains every file and its format.

- The `pan-*.txt` files are large (up to 5 MB): search them (grep) instead of
  reading them whole.
- Facts confirmed in the RS3 Beta client are in `slayer-vars.md`; treat other
  notes as research, not as confirmed game behaviour.
- Wiki-derived data is CC BY-NC-SA 3.0 (https://runescape.wiki).
